## 2. Implementation and architecture reconciliation

1. [ScheduleSheet](../../../../../MonoReport/Services/Xlsx/XlsxTemplatePlanner.Scheduling.cs#L8) indexes original parsed source nodes by numeric level and visits actual bound roots/ChildFirstIndices in encounter order using explicit enter/exit state. Header then Body emit on entry; Footer emits on exit. Unrendered data nodes remain transparent and preserve all descendants/ancestry. Source levels absent from data produce no blocks or phantom owners. Footer-only and body-only source roles work without a Body requirement or a source-parent matcher.
2. Each traversal item receives a full ordered data path, shared across its emitted roles. Source block references remain the parser's original objects. The existing structural equality/hash and [last-index current-item binding](../../../../../MonoReport/Services/Xlsx/XlsxTemplatePlanner.Instances.cs#L42) preserve distinct same-named items, real data parents and tuple provenance. The scheduler does not copy scalar values, construct another hierarchy, assign coordinates or add a horizontal plan/generalized IR.
3. [ExpansionGeometry](../../../../../MonoReport/Services/Xlsx/XlsxGeometryPlanner.Expansion.cs#L8) consumes the schedule and existing horizontal spans, sums complete block heights with checked arithmetic, and emits static gaps once. It does not choose vertical items or resolve fields. Its mismatch exception is now InvalidOperationException, outside the package-corruption ArgumentException catch filters in XlsxTemplateHandler; the new invariant test checks sheet and region-order mismatch.
4. [ProjectMerges](../../../../../MonoReport/Services/Xlsx/XlsxGeometryPlanner.Merges.cs#L83) now requires original vertical source-block containment, filters vertical candidates by overlapping source spans, and structurally deduplicates owners before projection. Original role blocks occupy disjoint source intervals, so this selects compatible instances without extra block IDs. The remaining exact-owner projection, meaningful nonanchor-content rejection, anchor retention, displaced-source ambiguity and horizontal ownership algorithms are preserved. Cross-block adjacency is deliberately rejected rather than repaired.
5. The public [nested preflight rejection](../../../../../MonoReport/Services/Xlsx/XlsxGeometryPlanner.Reports.cs#L23) remains unchanged. Public Analyze/Merge guard cases remain in the regression evidence for empty/null/nonempty input. Nested proof deliberately exercises the real internal pipeline without that activation gate; it does not fabricate schedules or prepared values. No M3.6 closure, descendant-range prefix matching/M3.7 formula semantics, new resource ceiling or later capability was introduced.
