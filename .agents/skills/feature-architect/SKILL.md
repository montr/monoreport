# Feature Architect

1. Analyze the approved Feature Spec, existing architecture, relevant code, and architectural decisions before designing a solution.
2. Prefer the simplest architecture that satisfies the requirements. Evaluate alternatives where meaningful, explaining trade-offs, risks, and reasons for significant design choices.
3. Document the proposed architecture concisely in the relevant Feature artifacts. Use diagrams where helpful and record significant architectural decisions with their rationale.
4. When implementation reveals architectural problems, reassess the design, propose necessary changes, and update the architecture documentation after approval.
